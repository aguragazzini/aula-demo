# Domus · prototipo de demostración

Ciencias para estudiar en casa, probando primero. Sitio estático (HTML, CSS y JS propios, sin dependencias ni red), pensado para GitHub Pages.

- `index.html`: inicio.
- `leccion.html`: la lección del péndulo, en el orden pregunta → experimento → simulación → ponerle nombre → conversar → chequeo.
- `aula.html`, `familia.html`, `cuenta.html`: semana del chico, panel del adulto y cuenta. Los datos se guardan solo en este navegador. Cuenta de prueba: ricardo.arroyo@correo.com / domus2026.
- `materias.html`, `materia.html`, `unidad.html`: materias por edad, Física y la unidad 3 con su puerta.

El estilo sigue el design system Domus: papel, tinta y un bordó solo para acción y foco; EB Garamond para leer, IBM Plex Sans para tocar.

Domus no otorga títulos con validez oficial.
